## 🚀 Öne Çıkan Projeler

### 🧾 KDV Çapraz Kontrol

[![KDV Çapraz Kontrol](https://img.shields.io/badge/GitHub-KDV_Çapraz_Kontrol-2ea44f?style=for-the-badge&logo=github)](https://github.com/ArdaEkiz0/kdv-capraz-kontrol)

e-Fatura (XML), PDF ve Excel faturalarınızı KDV kontrol cetveli ile otomatik karşılaştıran masaüstü uygulaması.

- ✅ Otomatik eşleştirme: tutar farkı, VKN farkı, mükerrer ve eksik belge tespiti
- 📄 XML fatura tipi/vergi detayı analizi, oran bazlı KDV doğrulama (Matrah × Oran = KDV)
- 📊 Excel + PDF raporları, KDV dağılımı, Ba Formu, grafikler ve dashboard
- 📧 SMTP/Outlook ile tek tıkla mail gönderimi
- 🔄 GitHub üzerinden otomatik güncelleme, GitHub Actions ile sürekli test

### 📋 Beyanname Takip

[![Beyanname Takip](https://img.shields.io/badge/GitHub-Beyanname_Takip-2ea44f?style=for-the-badge&logo=github)](https://github.com/ArdaEkiz0/beyanname-takip)

SMMM'ler için tasarlanmış, kendi bilgisayarında çalışan web tabanlı beyanname takip uygulaması.

- 📅 KDV, Muhtasar, Geçici Vergi, Kurumlar ve Gelir beyanname yönetimi
- ⏰ Otomatik aylık beyanname oluşturma, takvim ve teslim hatırlatıcıları
- 🏢 Mükellef yönetimi, müşteri portalı, WhatsApp/SMS bildirimleri
- 🔒 **Veriler yalnızca kendi bilgisayarında kalır** — sunucu yok, bulut yok
- 📱 PWA desteği ile çevrimdışı çalışma
