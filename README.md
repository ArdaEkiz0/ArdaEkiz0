## 🚀 Öne Çıkan Proje

### [BeyanTakip](https://github.com/ArdaEkiz0/beyanname-takip)
SMMM'ler için tasarlanmış, kendi bilgisayarında çalışan web tabanlı beyanname takip uygulaması.
- Mükellef ve beyanname yönetimi (KDV, Muhtasar, Geçici Vergi, Kurumlar, Gelir)
- Otomatik aylık beyanname oluşturma, takvim ve teslim hatırlatıcıları
- Mali haberler ve mevzuat takibi
- **Veriler yalnızca kendi bilgisayarında kalır** - sunucu yok, bulut yok
- PWA desteği ile çevrimdışı çalışma
